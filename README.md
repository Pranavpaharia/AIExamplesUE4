# AIExamplesUE4

Working examples of **artificial intelligence usage in Unreal Engine 4**, in C++.

A reference project demonstrating how to wire common AI techniques into UE4 gameplay: perception, pathfinding, behavior, and decision-making patterns with clean, commented examples.

## Examples included
- AI perception (sight/audio detection)
- Behavior Tree driven locomotion & combat flow
- Simple state-based behavior

## Requirements
- Unreal Engine 4.x (C++ project — Visual Studio 2019+ on Windows to rebuild)

## How to run
1. Clone and open the `.uproject`.
2. Generate project files and compile the C++ target.
3. Open the example map and press **Play**.
